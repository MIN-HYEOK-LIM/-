# 수출입 실적 통합 분석 (2024.01 ~ 2026.07, 31개월)

관세청 수출입무역통계 5종(총괄 · 품목별 · 성질별 수출 · 성질별 수입 · 신성질별)을 한 워크북으로
통합해 분석한 결과물입니다. 이번 자료부터 성질별이 수출·수입 두 파일로 나뉘어 들어와 양방향
분해가 가능해졌고, 기간이 3개 연도에 걸쳐 같은 달을 겹쳐 비교할 수 있습니다. 국가별 자료는 없습니다.

`data3.py`는 정렬용 파서, `hs_meta.py`는 HS 21개 부문 매핑과 97개 류의 구성 품목 설명입니다.

## 이번에 추가된 분석

- **MoM · QoQ · YoY** (`분석3`) — 월별 MoM(일평균 기준 병기)·YoY·YoY 3개월이평, 분기별 QoQ·YoY,
  연도별 비교. 2026 Q3는 7월만 포함된 부분분기라 증감률 계산에서 제외.
- **연도 오버레이** (`분석4`·`분석10`) — 1~12월을 가로축에 놓고 2024·2025·2026을 겹친 매트릭스 17종과
  같은 구조의 그래프 17종. 자료 없는 달은 비워 두어 2026년 선이 7월에서 끊깁니다.
- **반도체 vs 비반도체** (`분석5`) — HS 2단위 자료라 반도체를 단독으로 뽑을 수 없어 정의 3종
  (① IT부품 ② IT부품+IT제품 ③ HS85)을 병기. 월별 우위 판정과 국면 전환 추적 포함.
- **HS 부문 · 류 전수 분석** (`분석6`·`분석7`) — 21개 부문 전체(포함 류 명시)와 97개 류 전수.
  각 류의 주요 구성 품목, 물량·단가 분해로 성장 유형 자동 분류, 증감 의미를 문장으로 자동 판정.
- **성질별 양방향** (`분석8`) — 수출(식료/원료/경공업/중화학)과 수입(소비재/원자재/자본재) 분해.

## 핵심 결과

**3년 그림** — 1~7월 수출 3,922.7억$(2024) → 3,953.9억$(2025, +0.8%) → 5,950.6억$(2026, +50.5%).
2025년은 사실상 정체였고 도약은 2026년에 집중. 분기 YoY는 2025 Q1 −2.3%가 저점, 이후 계단식으로
올라 2026 Q2 +57.2%. QoQ도 2026 Q1 +16.4%, Q2 +24.7%로 두 분기 연속 두 자릿수.

**반도체 vs 비반도체** — 광의(IT부품+IT제품) 기준 1~7월 1,112.8 → 1,215.8(+9.3%) → 2,908.1억$(+139.2%).
비반도체는 2,809.9 → 2,738.1(−2.6%) → 3,042.5억$(+11.1%). **2025.01~2026.07 19개월 내내 반도체의
전년동월비가 비반도체를 앞섰고 단 한 달의 예외도 없습니다.** 2025년 수출이 플러스를 지킨 것은
전적으로 반도체 덕분(비반도체 −2.6%). 다만 2026년 들어 비반도체도 +11.1%로 반전, 6·7월은 +17.8%로 가속.
반도체 비중은 28.4% → 30.7% → 48.9%.

**HS 부문** — XVI부(기계·전기전자, 84·85류)가 +99.3%로 전체 증가분의 85.1%, 수출의 57.3%.
V부(광물성 생산품)는 2025년 −16.3% → 2026년 +34.5%로 반전. 같은 반전이 28류(−12.9%→+22.7%),
75류 니켈(−18.6%→+40.6%), 79류 아연(−14.0%→+31.1%)에서도 확인 — 원자재 가격 국면 전환 신호.

**HS 류** — 증가액 1위 HS85 +1,337.4억$(+108.6%, 2025년에는 +5.4%), 2위 HS84 +362.0억$(+75.5%,
2025년 +2.2%). 감소 최대는 HS87 자동차로 547.1 → 544.6 → 539.0억$ 2년 연속 감소.
성장 유형: 가격 주도 32류 / 물량 주도 11류 / 혼합 12류 / 감소 33류 / 단가 불안정 9류.
가격 주도 32류가 전체 증가분의 98.1%.

**물량 vs 가격** — 2025→2026 금액 증가 1,996.7억$ 중 가격효과 +2,260.5억(113.2%), 물량효과 −167.8억(−8.4%).
피셔 가격지수 1.514, 물량지수 0.994, 구성(믹스)효과 +3.8%p.

**정합성** — 총괄·성질별(수출)·성질별(수입)·신성질별 31개월 총계가 최대 6천달러 차이로 일치.
품목별 시트만 98류(특수분류) 누락으로 매년 0.03~0.05% 과소집계.
