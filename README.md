## 1단계 — 수출입 실적 분석 (2026.01 ~ 2026.07)

관세청 수출입무역통계 원본 파일(수출입 총괄 / 성질별 / 신성질별, 수리일 기준, 단위 건·톤·천달러)을
분석한 결과물입니다.

### 산출물

- `분석/수출입실적_분석_20260819.xlsx` — 원본 3개 시트는 수정하지 않고, 아래 6개 분석 시트를 추가한 파일
  - `분석1_정합성검증` — 개별항목 합 vs 총합(7종 검증)
  - `분석2_월별추이` — 총괄 지표, 조업일수 보정 일평균, 단가, 순상품교역조건
  - `분석3_품목별증감` — 성질별 21개·신성질별 17개 품목의 전월비/기간증감/기여도
  - `분석4_그래프` — 그래프 9종
  - `분석5_전년대비(입력)` — 2025년 값 입력 시 전년동월비 자동 계산
  - `분석6_해설` — 핵심 수치표 + 해석
- `분석/build_analysis.py` — 위 파일을 생성한 스크립트(원본 xlsx가 있으면 재현 가능)

모든 분석 셀은 원본 시트를 참조하는 수식이며, 하드코딩된 계산 결과는 없습니다.

### 핵심 결과 요약

**정합성** — 총괄 총계행 vs 월별 합계, 무역수지 항등식, 성질별·신성질별 대분류/중분류 합,
3개 시트 교차검증까지 전부 일치. 최대 편차는 금액 ±2천달러, 중량 ±0.2톤으로 원본 반올림에 따른
누적 오차 수준입니다.

**추이** — 수출은 1월 658.4억 달러 → 6월 1,019.6억 달러 → 7월 989.6억 달러(전월비 −2.9%).
7월은 조업일수가 6월보다 많아, 일평균 기준으로는 −9.0%로 실질 둔화입니다.
7개월 누계 수출 5,950.6억 달러, 수입 4,273.0억 달러, 무역수지 +1,677.6억 달러.

**구조** — 수출 중량은 +5.5%인데 금액은 +50.3%. 수출 단가가 3.933 → 5.603 천달러/톤(+42.5%)으로
성장의 대부분이 물량이 아닌 단가·품목믹스에서 나왔습니다. 순상품교역조건도 3.44 → 4.18배 개선.

**품목** — 1월→7월 수출 증가분 331.2억 달러 중 IT부품이 206.4억 달러(62.3%), IT제품까지 합쳐 72%.
7월 감소도 IT부품(−8.0%)·전기전자(−6.7%)·귀금속(−26.9%)에 집중된 조정입니다.

**한계** — 원본에 2025년 자료가 없어 전년 대비(YoY)는 산출하지 않았습니다(`분석5` 시트 입력 시 자동 계산).
성질별·신성질별 시트는 수출만 담고 있어 품목별 수입·품목별 무역수지는 계산할 수 없습니다.
