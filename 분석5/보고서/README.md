# 수출 데이터 분석 보고서 (워드, 5페이지)

`수출입실적_통합분석_2024-2026_섹터투자판_v2.xlsx`를 바탕으로 만든 바이사이드용 5페이지 보고서.
엑셀을 모르는 독자가 이 문서만 보고도 이해할 수 있도록, 원자료 출처와 가공 방법부터 설명한다.

**산출물** : `수출데이터_분석보고서.docx` (5페이지 · 그림 3 · 표 8)

## 구성

| 장 | 분량 | 내용 |
|---|---|---|
| 1. 분석 방법론 | 약 10% | 원자료(관세청 9개 파일)와 가공 방법, 분석 원칙 5가지, 등급 산정 방식 |
| 2. 데이터 해부 | 약 60% | 반도체/비반도체 월별 분해 · 가속도 순위 · 성장의 질 · 4단위 상세 · 산업 체인 · 마진 프록시 |
| 3. 투자 판단 | 약 30% | 비중확대 4섹터 · 전술적 비중확대 · 관찰 · 회피 · 포트폴리오 구성 · 리스크와 한계 |

## 작성 원칙

- **누계를 쓰지 않는다.** 1~7월 합산은 변화가 언제 시작됐는지를 감추므로, 모든 증감을 전년 같은 달과
  1:1로 비교했다. 표의 월별 열이 그 결과다.
- **반도체는 배경으로만 둔다.** 반도체가 좋다는 것은 이미 가격에 반영돼 있으므로, 전년 대비 급증했고
  2026년 들어 월별 속도가 빨라지는 비반도체 섹터에서 알파를 찾는 데 지면을 썼다.
- **독자가 엑셀을 모른다고 가정한다.** 모든 지표(가속도·성장동력·조업일수 보정)의 정의를 본문에서
  풀어 설명하고, 그림·표는 엑셀에서 그대로 가져와 캡션을 달았다.

## 핵심 결론

반도체를 뺀 수출은 2026년 1~7월 중 6개월 플러스(최근 3개월 +15.3%)로, 반도체만 좋았다는 통념과 다르다.
알파 후보는 **가속도가 플러스이면서 물량이 함께 늘어난** 곳이다.

| 등급 | 섹터 | 근거 |
|---|---|---|
| 비중확대 | 통신기기 · 계측검사장비 · 수동부품 · 정밀화학 | 가속 + 물량 두 조건 통과. 반도체 낙수가 실제 도달 |
| 위성(소액) | 철강 원료·반제품 · 봉형강 · 컴퓨터·서버 | 가속도 최상위이나 규모가 작아 분산 전제 |
| 관찰 | 자동차 완성차·부품 · 가전 | 턴어라운드 초입. 물량 전환 확인 후 진입 |
| 회피 | 정유 · 귀금속 소재 · 합성수지 · 이차전지 · 철강 판재 | 금액은 크나 가속도 소멸 또는 물량 부재 |

## 다시 만드는 법

```bash
npm install docx
node build2.js                                    # → 수출데이터_분석보고서.docx
soffice --headless --convert-to pdf 수출데이터_분석보고서.docx   # 확인용
```

- `head.js` — 스타일 헬퍼(표·그림·박스). `build2.js`가 이어붙여 쓴다.
- `data.js` — 본문 표의 수치. 전부 워크북에서 검산해 옮긴 값이다.
- `figs/` — 워크북 분석10 시트의 차트를 PDF로 렌더링해 잘라낸 이미지.
  (`분석10_그래프` 시트에 가로 방향·페이지 나누기를 넣어 차트당 한 페이지로 출력한 뒤 여백을 잘랐다.)

그림 크기는 PNG 헤더에서 실제 가로세로비를 읽어 계산한다. 비율을 고정값으로 두면 원본과 다른
모양의 차트가 눌려 보이고, 문단 기본 줄간격에 `lineRule`이 없으면 LibreOffice가 이를 고정 행높이로
해석해 이미지가 잘리므로 두 가지 모두 명시해야 한다.
