## 이 판에서 새로 드러난 것

### 비반도체도 2026년에는 좋습니다

반도체 4개 코드(8542·8473·8523·8541)를 뺀 나머지 수출입니다.

| | 2025 1~7 | 2026 1~7 | YoY | 조업보정 YoY | 최근 3M YoY |
|---|---:|---:|---:|---:|---:|
| 국가 총수출 | 3,954억$ | 5,951억$ | +50.5% | +49.5% | +62.2% |
| 반도체 4개 코드 | 928억$ | 2,573억$ | +177.3% | +175.5% | +197.2% |
| **비반도체** | **3,026억$** | **3,377억$** | **+11.6%** | **+10.8%** | **+15.3%** |

2026년 1~7월 중 6개월이 플러스입니다. 명목으로 유일한 마이너스인 2월(−4.6%)은 조업일수가
19일로 전년 22일보다 3일 적었던 달이고, **일평균으로 보정하면 +10.4%로 뒤집힙니다**
(대신 조업일수가 3.5일 늘었던 1월이 −2.6%가 됩니다). 「2026년은 반도체만 좋았다」는 통념은
이 데이터와 맞지 않습니다.

반도체 비중은 2025년 1월 21.8%에서 2026년 7월 45.9%로 올랐습니다.

### 같은 류 안에서 상류와 하류가 정반대로 움직입니다

2단위(류)로 보면 「화학」·「철강」이 한 덩어리지만, 4단위로 쪼개면 이렇게 갈립니다.

| 체인 | 상류 | 하류 | 격차 |
|---|---|---|---:|
| 화학 | 석유제품(정유) **+38.3%** | 플라스틱 가공품 +7.0% | +31.3%p |
| 철강 | 반제품·선철 **+32.8%**, 봉·형강 **+51.2%** | 열연 −12.0%, 도금강판 −5.3% | +38.1%p |
| 반도체 | 집적회로 +149.8% | 제조장비 +13.1%(물량 −5.6%) | +136.8%p |

정유가 +34.8%인 동안 석유화학 기초유분은 +5.3%에 그쳤습니다. **같은 원유를 쓰지만 정제와 석화는
완전히 다른 사이클**이어서, 「화학」으로 묶어 사면 정반대 두 사이클을 섞어 사는 셈입니다.

### 자동차 — 전동화가 2년 만에 다시 속도를 냈습니다

축전지(8507) ÷ 가솔린엔진(8407) 비율이 **5.43(2024) → 4.03(2025) → 6.34(2026)** 로
급반등했습니다. 가솔린엔진 −28.9%, 축전지 +11.9%. 2025년의 후퇴(전기차 캐즘)를 되돌린 것입니다.
완성차는 6·7월에 +5%, +7%로 2년 부진 끝에 플러스 전환했고, 부품은 7월에야 첫 플러스(+3%)가
나왔습니다.

### 그 밖에

- **철강 봉·형강 +28.5%** vs 판재 −6.6%. 판재/봉형강 비율이 10.18 → 6.16으로 −39.5%.
- **조선**은 단월로 −6%~+64%까지 널뛰지만 3개월 이동합으로 보면 2026년 내내 +11~30%로 가장 꾸준합니다.
- **가전**은 38개 섹터 중 유일하게 7개월 내내 감소(−18.0%)했습니다. 다만 6·7월 감소폭이 −6%, −5%로 줄었습니다.
- **귀금속 소재**(금 +258%, 은 +132%)는 증가율 1위이자 가속도 −110.9%p로 유일한 뚜렷한 피크아웃 신호입니다.
- 물량 주도(실수요형) 성장 : 계측·검사장비 +21.3%, 정밀·기능성 화학 +18.6%, 의료기기 +8.1%, 철강 봉형강·원료.

## 방법론

- **3M YoY** : 최근 3개월(2026.05~07)을 전년 동월과 비교. 누계 YoY의 시차를 없애기 위함.
- **가속도** : 3M YoY − 직전 3M YoY(2026.02~04). 부호 조합으로 국면을 자동 판정
  (둘 다 + = 가속 성장 / +,− = 성장 둔화 / −,+ = 바닥 통과 / 둘 다 − = 침체 심화).
- **성장동력** : 금액 증가를 단가와 물량으로 분해. 단가가 물량의 2배 이상이면 `가격 주도`(사이클),
  물량이 2배 이상이면 `물량 주도`(실수요).
- **조업일수 보정** : 금액 ÷ 조업일수로 일평균을 낸 뒤 전년 동월의 일평균과 비교. 설 연휴 이동 등
  달력 효과를 걷어냅니다.
- **종합점수** : 성장(30) + 가속도(25) + 성장동력×증가월수(20) + 규모(15) + 변동성 역수(10).
- **등급** : 종합점수와 국면의 조합. 규모가 작고 변동성이 큰 섹터(변동성 1.2 초과)는 `비중확대`에서 제외합니다.

## 한계

- 무역통계 기반 정량 스크리닝입니다. 개별 기업의 실적·밸류에이션·수급은 반영돼 있지 않으므로
  종목 선택은 별도 검증이 필요합니다.
- 단가는 **톤당 단가**입니다. 대당·개당 ASP의 방향을 가늠하는 근사치이지 ASP 자체가 아니며,
  품목 믹스가 바뀌면 함께 움직입니다.
- 4단위 데이터는 10개 류(27·29·39·71·72·84·85·87·89·90)에 한정됩니다. 나머지 영역은
  분석3 [C]의 HS 21개 부문 표로 커버합니다(농수산·섬유·비금속 등 포함).
- 품목별(HS) 합계는 특수분류 HS 98이 빠져 총괄 대비 0.03~0.05% 작습니다. 분석1 [E]에 검증돼 있습니다.
- 조선·방산처럼 인도·계약 시점에 금액이 몰리는 섹터는 단월 증감률이 추세를 나타내지 않습니다.
  3개월 이동합(분석6)으로 보십시오.

## 다시 만드는 법

```bash
cp 원본2단위/*.xlsx .        # 스크립트는 원본을 같은 디렉터리에서 찾습니다
python3 v3_a.py              # 원본 9개 시트 무수정 통합   → s1.xlsx
python3 v3_b.py              # 텍스트 숫자 정제 시트        → s2.xlsx
python3 v4_pivot.py          # HS4 피벗 4종                → s2b.xlsx
python3 build.py             # 분석 10개 시트 전체          → final4.xlsx
python3 recalc.py final4.xlsx 1800   # LibreOffice 수식 계산
```

`build.py`가 `fbase.py`(공통 헬퍼)와 `f_*.py`(시트별 빌더)를 순서대로 실행합니다.
`v3_a.py`를 고쳐 원본 시트를 추가했다면 **반드시 `v3_b.py`부터 다시 돌려야 합니다.**
s2.xlsx가 낡은 채로 v4_pivot.py를 돌리면 없는 시트를 참조하게 되고,
`IFERROR(...,0)`이 그 오류를 0으로 삼켜 조용히 전부 0이 됩니다.
