# 수출입실적 통합분석 (2024.01~2026.07) — HS 4단위 · 섹터 투자판

관세청 수출입실적 원본 9개 파일(2단위 5 + 4단위 4)을 한 파일로 모으고,
**원본 시트는 한 셀도 고치지 않은 채** 분석 시트 22종을 덧붙인 결과물입니다.
분석 셀은 전부 원본을 참조하는 수식(총 119,294개)이라, 원본에 다음 달이 추가되면
범위만 늘려 다시 계산하면 분석 전체가 갱신됩니다.

**산출물** : `수출입실적_통합분석_2024-2026_HS4단위_섹터투자판.xlsx` (42시트 · 차트 37개 · 수식 오류 0)

## 이번 판에서 새로 한 것

1. **HS 4단위 321개 코드 반영** — 10개 류(27·29·39·71·72·84·85·87·89·90)를 4단위로 분해.
   2단위는 성격이 다른 품목이 섞여 있어(예: 84류 = 일반기계 + 메모리 모듈) 투자 판단에 쓸 수 없었습니다.
2. **「반도체 vs 비반도체」를 40개 밸류체인 섹터로 재편** — 소자·모듈·저장장치·개별소자·장비·검사계측·
   소재까지 단계별로 분리. 321개 코드 전부가 어느 한 섹터에 배정되어 미분류가 없습니다.
3. **투자 판단 레이어 신설** (분석14~22) — 스코어보드·스크리너·마진 프록시·투자 아이디어·산점도.

## 방법론

- **3M YoY** : 최근 3개월(2026.05~07)을 전년 동월과 비교. 누계 YoY의 시차를 없애기 위함.
- **가속도** : 3M YoY − 직전 3M YoY(2026.02~04). 부호 조합으로 국면을 자동 판정합니다.
  (둘 다 + = 가속 성장 / +,− = 성장 둔화 / −,+ = 바닥 통과 / 둘 다 − = 침체 심화)
- **성장동력** : 금액 증가를 단가 변화와 물량 변화로 분해. 단가가 물량의 2배 이상이면 `가격 주도`
  (사이클, 되돌림 위험), 물량이 2배 이상이면 `물량 주도`(실수요, 지속성 높음).
- **종합점수** : 성장(30) + 가속도(25) + 성장동력×증가월수(20) + 규모(15) + 변동성 역수(10).
- **마진 프록시** : 수출 톤당 단가 ÷ 수입 톤당 단가. 절대 수준이 아니라 **방향**을 봅니다.

## 한계

- 무역통계 기반 정량 스크리닝입니다. 개별 기업의 실적·밸류에이션·수급은 전혀 반영돼 있지 않으므로
  종목 선택은 별도 검증이 필요합니다.
- 단가는 **톤당 단가**입니다. 대당·개당 ASP의 방향을 가늠하는 근사치이지 그 자체가 ASP는 아닙니다.
- 4단위 데이터는 10개 류에 한정됩니다. 나머지 류는 2단위까지만 분석돼 있습니다
  (그래서 S07 반도체 소재, S32 철강 강관 섹터는 해당 류 미수집으로 비어 있습니다).
- 품목별(HS) 합계는 특수분류 HS 98이 빠져 총괄 대비 0.03~0.05% 작습니다. 분석1에 검증돼 있습니다.

## 다시 만드는 법

```bash
cp 원본2단위/*.xlsx .        # 스크립트는 원본을 같은 디렉터리에서 찾습니다
python3 v3_a.py              # 원본 9개 시트 무수정 통합      → s1.xlsx

python3 v3_c.py              # 분석1~22 전체 (v3_m/v3_d/v4_e를 순차 실행) → final3.xlsx

```

`v3_a.py`를 고쳐 원본 시트를 추가했다면 **반드시 `v3_b.py`부터 다시 돌려야 합니다.**
s2.xlsx가 낡은 채로 v4_pivot.py를 돌리면 없는 시트를 참조하게 되고,
`IFERROR(...,0)`이 그 오류를 0으로 삼켜 조용히 전부 0이 됩니다.
