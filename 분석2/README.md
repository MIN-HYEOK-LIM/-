## 핵심 결과

**정합성** — 총괄·성질별·신성질별·국가별의 19개월 총계는 최대 27천달러(0.000002%) 차이로 일치.
단 **품목별 시트만 매월 체계적으로 작습니다**(수출 −499,459천달러 / −0.038%, 수입 −384,287천달러).
원본을 확인한 결과 이 시트에는 HS 01~97류 중 96개(77류는 HS 결번)와 값이 0인 99류만 있고
**98류(특수분류)가 통째로 없습니다**. 품목별 시트로 총액을 대체하면 그만큼 과소집계됩니다.

**총량** — 2026.1~7 수출 5,950.6억 달러(+50.5% YoY), 수입 4,273.0억 달러(+18.2%),
무역수지 339.3억 → 1,677.6억 달러. 조업일수는 +0.6%뿐이라 달력 효과가 아닌 실질 증가입니다
(일평균 수출 +49.5%). 전년동월비는 2026.06 +70.4%로 정점, 7월 +63.0%.

**구조** — 수출 중량은 −4.2%인데 금액은 +50.5%. 수출 단가 3.446 → 5.416 천달러/톤(+57.2%),
수입 단가는 +16.8%에 그쳐 순상품교역조건이 2.955 → 3.978배로 개선. 흑자 확대의 실체는
물량이 아니라 단가 격차입니다.

**품목** — HS 85류(전기기기·반도체)가 +1,337.4억 달러로 전체 수출 증가분의 67.0%, 84류(기계류)가 18.1%.
신성질별로는 IT부품 +149.0%(기여도 73.2%), IT제품 +98.1%. 반대로 소비재 −0.4%, 87류(차량) −1.0%.
적자는 27류(광물성 연료) −557.4억, 26류(광·슬래그) −147.8억 달러.

**국가** — 중국 +496.7억(기여도 24.9%), 미국 +384.8억(19.3%), 홍콩 +277.8억(13.9%),
베트남·대만까지 상위 5개국이 증가분의 76%. 대중 무역수지는 −82.8억 → +188.5억 달러로 흑자 전환.
상위 5개국 비중 56.2% → 62.1%, 중국·홍콩·대만 합계 27.1% → 34.4%로 지역 집중 심화.

**한계** — 2026년은 7개월치뿐이라 연간 비교 불가(연환산은 참고치). 국가별에는 중량이 없어
국가별 단가 분석 불가, 성질별에는 수입이 없어 성질별 무역수지 산출 불가. 명목 달러 기준이며
환율·물가 미조정.
